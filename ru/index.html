Что такое Stick?

Stick — настольное и веб-приложение для анимации человечков из палочек. Перетаскивайте суставы, чтобы поставить позу, добавьте кадр, измените позу — и Stick сам заполнит движение между ними. Есть таймлайн со слоями, калька (onion skin), движения камеры, визуальные эффекты, кисти для рисования от руки и редактор ригов для своих персонажей.

Stick открывает проекты Pivot Animator (.piv, .stk) и Stick Nodes, так что старые анимации можно продолжить. Всё работает на вашем компьютере: без аккаунта, без водяных знаков, без загрузок в сеть.

Возможности

Поза любым суставом

Тяните за руки и ноги — инверсная кинематика (IK) сама согнёт локти и колени. Фиксация углов, растягиваемые узлы и 3D-детали.

Ключевые кадры и воспроизведение

Добавьте кадр, измените позу, нажмите «Воспроизвести». Промежуточные кадры, кривые сглаживания и воспроизведение на WebGPU в реальном времени.

Настоящий таймлайн

Простая лента кадров или расширенный таймлайн со слоями, папками, ключами, сглаживанием, диапазонами, калькой и аудиодорожками.

Встроенные эффекты

Свечение, аура, тень, размытие, частицы, энергетические лучи, взрывы, дым и усиления — с ключами на каждый кадр.

Рисуйте на любом кадре

Тушь, кисть, карандаш, линер, маркер, уголь, аэрограф, мел, масло и другое. Сочетайте рисунок от руки с ригами.

Создавайте свои риги

Собирайте персонажей из линий, кругов, многоугольников, текста и картинок. Начните с примеров: шестерни, веер, ящики и 3D-фигуры.

Любая команда — через поиск

Нажмите F1 или Ctrl+P, чтобы найти любую команду. Все сочетания клавиш можно изменить.

Светлая или тёмная тема, 27 языков

Тёмная тема по умолчанию, светлая — по желанию, масштаб интерфейса и сенсорный режим для планшетов.

Экспорт куда угодно

Пресеты в один клик для YouTube, YouTube Shorts, TikTok, Instagram Reels, X, GIF для чатов, прозрачных PNG и 4K. Экспорт в MP4, WebM (с прозрачностью), GIF, APNG, последовательности PNG / JPEG / SVG или редактируемые файлы .piv и .stk.

Вопросы и ответы

Stick бесплатный?

Да. Stick бесплатный и с открытым кодом по лицензии GPL-3.0. Без аккаунта, без водяных знаков, без платной версии.

Это альтернатива Pivot Animator?

Да. Stick открывает проекты (.piv) и фигуры (.stk) Pivot Animator и умеет экспортировать их обратно, добавляя слои, промежуточные кадры, эффекты, рисование и современный рендер на WebGPU.

Можно открыть проекты Stick Nodes на ПК?

Да. Stick импортирует фигуры, мувиклипы и проекты Stick Nodes, чтобы вы продолжили работу на Windows или Linux.

Как сделать анимацию стикмена?

Поставьте позу, перетаскивая суставы, нажмите Добавить кадр (A), измените позу и нажмите Пробел для воспроизведения. Stick заполнит движение между кадрами. Затем нажмите Экспорт и выберите MP4, GIF или пресет, например TikTok.

Работает ли без интернета? Загружает ли мои анимации?

Полностью работает офлайн. Проекты хранятся только на вашем компьютере, ничего не загружается.

Сборка из исходников

Требования: Node.js 22+ и Python 3.11+.

git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # настольное приложение (Electron)
npm run serve        # или редактор в браузере: http://127.0.0.1:47831
