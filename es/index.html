¿Qué es Stick?

Stick es una app de escritorio y web para animación de monigotes (stick figures). Arrastras las articulaciones para posar la figura, añades un fotograma, la vuelves a posar y Stick rellena el movimiento intermedio. Tiene una línea de tiempo con capas, papel cebolla, movimientos de cámara, efectos visuales, pinceles para dibujar a mano y un editor de rigs para personajes propios.

Abre proyectos de Pivot Animator (.piv, .stk) y Stick Nodes, así que puedes seguir con tus animaciones antiguas. Todo funciona en tu ordenador: sin cuenta, sin marca de agua, sin subidas.

Funciones

Posa cualquier articulación

Arrastra manos y pies; la cinemática inversa (IK) dobla codos y rodillas por ti. Bloqueo de ángulos, nodos elásticos y piezas 3D.

Fotogramas clave y reproducción

Añade un fotograma, cambia la pose y dale a reproducir. Interpolación, curvas de suavizado y reproducción WebGPU en tiempo real.

Una línea de tiempo de verdad

Tira de fotogramas simple o línea de tiempo avanzada con capas, carpetas, claves, suavizado, rangos, papel cebolla y pistas de audio.

Efectos integrados

Brillo, aura, sombra, desenfoque, partículas, rayos de energía, explosiones, humo y power-ups, animables por fotograma.

Dibuja en cualquier fotograma

Tinta, pincel, lápiz, rotulador, marcador, carboncillo, aerógrafo, tiza, óleo y más. Mezcla dibujo a mano con tus rigs.

Crea tus propios rigs

Crea personajes con líneas, círculos, polígonos, texto e imágenes. Empieza con ejemplos como engranajes, abanicos, cajas y formas 3D.

Todos los comandos, a una búsqueda

Pulsa F1 o Ctrl+P para encontrar cualquier comando. Todos los atajos se pueden cambiar.

Claro u oscuro, en 27 idiomas

Tema oscuro por defecto, tema claro cuando quieras, escala de interfaz ajustable y diseño táctil para tabletas.

Exporta a cualquier sitio

Ajustes de un clic para YouTube, YouTube Shorts, TikTok, Instagram Reels, X, GIF para chats, PNG transparentes y 4K. Exporta MP4, WebM (con transparencia), GIF, APNG, secuencias PNG / JPEG / SVG o archivos editables .piv y .stk.

Preguntas frecuentes

¿Stick es gratis?

Sí. Stick es gratis y de código abierto bajo la licencia GPL-3.0. Sin cuenta, sin marca de agua y sin versión de pago.

¿Es una alternativa a Pivot Animator?

Sí. Stick abre proyectos (.piv) y figuras (.stk) de Pivot Animator y puede volver a exportarlos. Además añade capas, interpolación, efectos, dibujo y un renderizador WebGPU moderno.

¿Puedo abrir proyectos de Stick Nodes en PC?

Sí. Stick importa figuras, movieclips y proyectos de Stick Nodes para que sigas trabajando en Windows o Linux.

¿Cómo hago una animación de monigotes?

Posa la figura arrastrando sus articulaciones, pulsa Añadir fotograma (A), cambia la pose y pulsa Espacio para reproducir. Stick interpola el movimiento. Luego pulsa Exportar y elige MP4, GIF o un ajuste como TikTok.

¿Funciona sin conexión? ¿Sube mis animaciones?

Funciona totalmente sin conexión. Tus proyectos se quedan en tu ordenador; no se sube nada.

Compilar desde el código

Requisitos: Node.js 22+ y Python 3.11+.

git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # app de escritorio (Electron)
npm run serve        # o el editor en tu navegador: http://127.0.0.1:47831
