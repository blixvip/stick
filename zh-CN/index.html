什么是 Stick？

Stick 是一款用于制作火柴人动画的桌面和网页应用。拖动关节摆出姿势，添加一帧，再换个姿势，Stick 会自动补间中间的动作。它拥有带图层的时间轴、洋葱皮、镜头运动、视觉特效、手绘笔刷，以及用于自定义角色的骨骼编辑器。

它可以打开 Pivot Animator（.piv、.stk）和 Stick Nodes 项目，旧作品可以直接继续编辑。所有操作都在你的电脑上完成：无需账号、没有水印、不会上传。

功能

随心摆姿势

拖动手和脚，反向动力学（IK）会自动弯曲手肘和膝盖。支持角度锁定、可伸缩节点和 3D 部件。

关键帧与播放

添加一帧、改变姿势、点击播放。补间、缓动曲线和实时 WebGPU 播放让长动画依然流畅。

专业时间轴

简单帧条或高级时间轴：图层、文件夹、关键帧、缓动、播放范围、洋葱皮和音轨。

内置特效

发光、光环、阴影、模糊、粒子、能量光束、爆炸、烟雾和能量提升，可逐帧设置关键帧。

在任意帧上手绘

墨水、毛笔、铅笔、针管笔、马克笔、炭笔、喷枪、粉笔、油画等笔刷，手绘与骨骼动画自由混合。

打造自己的角色

用线条、圆形、多边形、文字和图片制作角色，可从齿轮、折扇、箱子和 3D 形状等示例开始。

一键搜索所有命令

按 F1 或 Ctrl+P 查找任何命令，所有快捷键都可自定义。

深色或浅色，27 种语言

默认深色主题，也可切换浅色；支持界面缩放和平板触控布局。

随处导出

一键预设：YouTube、YouTube Shorts、抖音 / TikTok、Instagram Reels、X、聊天用 GIF、透明 PNG 序列和 4K。支持导出 MP4、WebM（含透明通道）、GIF、APNG、PNG / JPEG / SVG 序列，以及可编辑的 .piv 和 .stk 文件。

常见问题

Stick 免费吗？

Stick 完全免费，基于 GPL-3.0 协议开源。无需账号，没有水印，也没有付费版本。

Stick 可以替代 Pivot Animator 吗？

可以。Stick 能打开 Pivot Animator 的项目（.piv）和人物（.stk），也能导出回去，并新增了分层时间轴、补间、特效、手绘和现代 WebGPU 渲染。

能在电脑上打开 Stick Nodes 项目吗？

可以。Stick 支持导入 Stick Nodes 的人物、影片剪辑和项目，可以在 Windows 或 Linux 电脑上继续制作。

如何制作火柴人动画？

拖动关节摆好姿势，按 添加帧（A），改变姿势，然后按 空格 播放。Stick 会补间两帧之间的动作。最后点击 导出，选择 MP4、GIF 或 TikTok 等预设。

可以离线使用吗？会上传我的作品吗？

完全支持离线使用。你的项目只保存在自己的电脑上，不会上传。

从源码构建

环境要求：Node.js 22+ 和 Python 3.11+。

git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # 桌面应用（Electron）
npm run serve        # 或在浏览器中打开编辑器: http://127.0.0.1:47831
