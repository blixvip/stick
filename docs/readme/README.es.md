## ¿Qué es Stick?

**Stick** es una app de escritorio y web para **animación de monigotes** (stick figures). Arrastras las articulaciones para posar la figura, añades un fotograma, la vuelves a posar y Stick rellena el movimiento intermedio. Tiene una línea de tiempo con capas, papel cebolla, movimientos de cámara, efectos visuales, pinceles para dibujar a mano y un editor de rigs para personajes propios.

Abre proyectos de **Pivot Animator** (`.piv`, `.stk`) y **Stick Nodes**, así que puedes seguir con tus animaciones antiguas. Todo funciona en tu ordenador: sin cuenta, sin marca de agua, sin subidas.

## Consigue Stick

- **Compílalo tú mismo** con unos pocos comandos; mira [Compilar desde el código](#compilar-desde-el-código). Funciona como app de escritorio o en el navegador.
- **Instaladores:** las versiones para Windows (instalador y portable) y Linux (AppImage) se publican en la [página de Releases](https://github.com/blixvip/stick/releases). Pulsa **Watch → Custom → Releases** para recibir avisos.
- **Míralo primero:** el [vídeo de 2 minutos](https://github.com/blixvip/stick/releases/download/showcase/stick-editor-preview.mp4).

## Preguntas frecuentes

<details>
<summary><b>¿Stick es gratis?</b></summary>

Sí. Stick es gratis y de código abierto bajo la licencia GPL-3.0. Sin cuenta, sin marca de agua y sin versión de pago.
</details>

<details>
<summary><b>¿Es una alternativa a Pivot Animator?</b></summary>

Sí. Stick abre proyectos (<code>.piv</code>) y figuras (<code>.stk</code>) de Pivot Animator y puede volver a exportarlos. Además añade capas, interpolación, efectos, dibujo y un renderizador WebGPU moderno.
</details>

<details>
<summary><b>¿Puedo abrir proyectos de Stick Nodes en PC?</b></summary>

Sí. Stick importa figuras, movieclips y proyectos de Stick Nodes para que sigas trabajando en Windows o Linux.
</details>

<details>
<summary><b>¿Cómo hago una animación de monigotes?</b></summary>

Posa la figura arrastrando sus articulaciones, pulsa <b>Añadir fotograma</b> (<kbd>A</kbd>), cambia la pose y pulsa <kbd>Espacio</kbd> para reproducir. Stick interpola el movimiento. Luego pulsa <b>Exportar</b> y elige MP4, GIF o un ajuste como TikTok.
</details>

<details>
<summary><b>¿Funciona sin conexión? ¿Sube mis animaciones?</b></summary>

Funciona totalmente sin conexión. Tus proyectos se quedan en tu ordenador; no se sube nada.
</details>

## Compilar desde el código

Requisitos: Node.js 22+ y Python 3.11+.

```sh
git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # app de escritorio (Electron)
npm run serve        # o el editor en tu navegador: http://127.0.0.1:47831
```
