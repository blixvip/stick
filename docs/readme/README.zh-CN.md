## 什么是 Stick？

**Stick** 是一款用于制作**火柴人动画**的桌面和网页应用。拖动关节摆出姿势，添加一帧，再换个姿势，Stick 会自动补间中间的动作。它拥有带图层的时间轴、洋葱皮、镜头运动、视觉特效、手绘笔刷，以及用于自定义角色的骨骼编辑器。

它可以打开 **Pivot Animator**（`.piv`、`.stk`）和 **Stick Nodes** 项目，旧作品可以直接继续编辑。所有操作都在你的电脑上完成：无需账号、没有水印、不会上传。

## 常见问题

<details>
<summary><b>Stick 免费吗？</b></summary>

Stick 完全免费，基于 GPL-3.0 协议开源。无需账号，没有水印，也没有付费版本。
</details>

<details>
<summary><b>Stick 可以替代 Pivot Animator 吗？</b></summary>

可以。Stick 能打开 Pivot Animator 的项目（<code>.piv</code>）和人物（<code>.stk</code>），也能导出回去，并新增了分层时间轴、补间、特效、手绘和现代 WebGPU 渲染。
</details>

<details>
<summary><b>能在电脑上打开 Stick Nodes 项目吗？</b></summary>

可以。Stick 支持导入 Stick Nodes 的人物、影片剪辑和项目，可以在 Windows 或 Linux 电脑上继续制作。
</details>

<details>
<summary><b>如何制作火柴人动画？</b></summary>

拖动关节摆好姿势，按 <b>添加帧</b>（<kbd>A</kbd>），改变姿势，然后按 <kbd>空格</kbd> 播放。Stick 会补间两帧之间的动作。最后点击 <b>导出</b>，选择 MP4、GIF 或 TikTok 等预设。
</details>

<details>
<summary><b>可以离线使用吗？会上传我的作品吗？</b></summary>

完全支持离线使用。你的项目只保存在自己的电脑上，不会上传。
</details>

## 从源码构建

环境要求：Node.js 22+ 和 Python 3.11+。

```sh
git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # 桌面应用（Electron）
npm run serve        # 或在浏览器中打开编辑器: http://127.0.0.1:47831
```
