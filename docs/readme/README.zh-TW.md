## Stick 是什麼？

**Stick** 是一款用來製作**火柴人動畫**的桌面與網頁應用程式。拖曳關節擺出姿勢，新增一個影格，再換個姿勢，Stick 就會自動補間中間的動作。它擁有含圖層的時間軸、洋蔥皮、鏡頭運動、視覺特效、手繪筆刷，以及自訂角色的骨架編輯器。

它可以開啟 **Pivot Animator**（`.piv`、`.stk`）與 **Stick Nodes** 專案，舊作品能直接繼續編輯。所有處理都在你的電腦上完成：不需帳號、沒有浮水印、不會上傳。

## 取得 Stick

- **自行建置**：只要幾個指令，請見[從原始碼建置](#從原始碼建置)。可作為桌面應用程式執行，也能在瀏覽器中執行。
- **安裝檔**：Windows（安裝版與可攜版）和 Linux（AppImage）版本發布在 [Releases 頁面](https://github.com/blixvip/stick/releases)。點選 **Watch → Custom → Releases** 取得更新通知。
- **先看示範**：[2 分鐘影片導覽](https://blixvip.github.io/stick/#tour)。

⭐ **為本儲存庫按下 Star**，追蹤新版本，也讓更多動畫創作者發現 Stick。

## 常見問題

<details>
<summary><b>Stick 免費嗎？</b></summary>

Stick 完全免費，採用 GPL-3.0 授權開源。不需帳號，沒有浮水印，也沒有付費版本。
</details>

<details>
<summary><b>Stick 可以取代 Pivot Animator 嗎？</b></summary>

可以。Stick 能開啟 Pivot Animator 的專案（<code>.piv</code>）與人物（<code>.stk</code>），也能匯出回去，並加入分層時間軸、補間、特效、手繪與現代 WebGPU 繪圖。
</details>

<details>
<summary><b>可以在電腦上開啟 Stick Nodes 專案嗎？</b></summary>

可以。Stick 能匯入 Stick Nodes 的人物、影片片段與專案，讓你在 Windows 或 Linux 電腦上繼續創作。
</details>

<details>
<summary><b>要怎麼製作火柴人動畫？</b></summary>

拖曳關節擺好姿勢，按 <b>新增影格</b>（<kbd>A</kbd>），改變姿勢，再按 <kbd>空白鍵</kbd> 播放。Stick 會補間影格之間的動作。最後按 <b>匯出</b>，選擇 MP4、GIF 或 TikTok 等預設。
</details>

<details>
<summary><b>可以離線使用嗎？會上傳我的作品嗎？</b></summary>

完全可以離線使用。你的專案只存在自己的電腦上，不會上傳。
</details>

## 從原始碼建置

需求：Node.js 22+ 與 Python 3.11+。

```sh
git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # 桌面應用程式（Electron）
npm run serve        # 或在瀏覽器中開啟編輯器: http://127.0.0.1:47831
```
