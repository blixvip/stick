## Qu’est-ce que Stick ?

**Stick** est une application de bureau et web pour l’**animation de bonhommes allumettes**. Vous faites glisser les articulations pour poser le personnage, ajoutez une image, changez la pose, et Stick remplit le mouvement entre les deux. Il propose une timeline à calques, la pelure d’oignon, des mouvements de caméra, des effets visuels, des pinceaux pour dessiner à la main et un éditeur de rigs pour vos propres personnages.

Il ouvre les projets **Pivot Animator** (`.piv`, `.stk`) et **Stick Nodes** : vos anciennes animations vous suivent. Tout fonctionne sur votre ordinateur : pas de compte, pas de filigrane, aucun envoi.

## Obtenir Stick

- **Compilez-le vous-même** en quelques commandes ; voir [Compiler depuis les sources](#compiler-depuis-les-sources). Il fonctionne en application de bureau ou dans le navigateur.
- **Installateurs :** les versions Windows (installateur et portable) et Linux (AppImage) sont publiées sur la [page des Releases](https://github.com/blixvip/stick/releases). Cliquez sur **Watch → Custom → Releases** pour être prévenu.

## FAQ

<details>
<summary><b>Stick est-il gratuit ?</b></summary>

Oui. Stick est gratuit et open source sous licence GPL-3.0. Pas de compte, pas de filigrane, pas de version payante.
</details>

<details>
<summary><b>Est-ce une alternative à Pivot Animator ?</b></summary>

Oui. Stick ouvre les projets (<code>.piv</code>) et les figures (<code>.stk</code>) de Pivot Animator et peut les réexporter, avec en plus des calques, l’interpolation, des effets, le dessin et un rendu WebGPU moderne.
</details>

<details>
<summary><b>Puis-je ouvrir des projets Stick Nodes sur PC ?</b></summary>

Oui. Stick importe les figures, movieclips et projets Stick Nodes pour continuer sur Windows ou Linux.
</details>

<details>
<summary><b>Comment faire une animation de bonhomme allumette ?</b></summary>

Posez le personnage en faisant glisser ses articulations, appuyez sur <b>Ajouter une image</b> (<kbd>A</kbd>), changez la pose et appuyez sur <kbd>Espace</kbd> pour lire. Stick interpole le mouvement. Cliquez ensuite sur <b>Exporter</b> et choisissez MP4, GIF ou un préréglage comme TikTok.
</details>

<details>
<summary><b>Fonctionne-t-il hors ligne ? Envoie-t-il mes animations ?</b></summary>

Il fonctionne entièrement hors ligne. Vos projets restent sur votre ordinateur ; rien n’est envoyé.
</details>

## Compiler depuis les sources

Prérequis : Node.js 22+ et Python 3.11+.

```sh
git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # application de bureau (Electron)
npm run serve        # ou l’éditeur dans votre navigateur: http://127.0.0.1:47831
```
