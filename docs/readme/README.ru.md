## Что такое Stick?

**Stick** — настольное и веб-приложение для **анимации человечков из палочек**. Перетаскивайте суставы, чтобы поставить позу, добавьте кадр, измените позу — и Stick сам заполнит движение между ними. Есть таймлайн со слоями, калька (onion skin), движения камеры, визуальные эффекты, кисти для рисования от руки и редактор ригов для своих персонажей.

Stick открывает проекты **Pivot Animator** (`.piv`, `.stk`) и **Stick Nodes**, так что старые анимации можно продолжить. Всё работает на вашем компьютере: без аккаунта, без водяных знаков, без загрузок в сеть.

## Вопросы и ответы

<details>
<summary><b>Stick бесплатный?</b></summary>

Да. Stick бесплатный и с открытым кодом по лицензии GPL-3.0. Без аккаунта, без водяных знаков, без платной версии.
</details>

<details>
<summary><b>Это альтернатива Pivot Animator?</b></summary>

Да. Stick открывает проекты (<code>.piv</code>) и фигуры (<code>.stk</code>) Pivot Animator и умеет экспортировать их обратно, добавляя слои, промежуточные кадры, эффекты, рисование и современный рендер на WebGPU.
</details>

<details>
<summary><b>Можно открыть проекты Stick Nodes на ПК?</b></summary>

Да. Stick импортирует фигуры, мувиклипы и проекты Stick Nodes, чтобы вы продолжили работу на Windows или Linux.
</details>

<details>
<summary><b>Как сделать анимацию стикмена?</b></summary>

Поставьте позу, перетаскивая суставы, нажмите <b>Добавить кадр</b> (<kbd>A</kbd>), измените позу и нажмите <kbd>Пробел</kbd> для воспроизведения. Stick заполнит движение между кадрами. Затем нажмите <b>Экспорт</b> и выберите MP4, GIF или пресет, например TikTok.
</details>

<details>
<summary><b>Работает ли без интернета? Загружает ли мои анимации?</b></summary>

Полностью работает офлайн. Проекты хранятся только на вашем компьютере, ничего не загружается.
</details>

## Сборка из исходников

Требования: Node.js 22+ и Python 3.11+.

```sh
git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # настольное приложение (Electron)
npm run serve        # или редактор в браузере: http://127.0.0.1:47831
```
