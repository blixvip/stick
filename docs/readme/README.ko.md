## Stick이란?

**Stick**은 **졸라맨(스틱맨) 애니메이션**을 위한 데스크톱·웹 앱입니다. 관절을 끌어 포즈를 잡고, 프레임을 추가해 다시 포즈를 바꾸면 그 사이 동작을 Stick이 자동으로 채워 줍니다. 레이어 타임라인, 어니언 스킨, 카메라 무빙, 시각 효과, 손그림 브러시, 나만의 캐릭터를 위한 리그 빌더를 갖추고 있습니다.

**Pivot Animator**(`.piv`, `.stk`)와 **Stick Nodes** 프로젝트도 열 수 있어 예전 작업을 그대로 이어갈 수 있습니다. 모든 작업은 내 컴퓨터에서 처리됩니다. 계정, 워터마크, 업로드가 없습니다.

## Stick 받기

- **직접 빌드**: 명령 몇 줄이면 됩니다. [소스에서 빌드](#소스에서-빌드)를 참고하세요. 데스크톱 앱이나 브라우저에서 실행됩니다.
- **설치 파일**: Windows(설치판, 포터블)와 Linux(AppImage) 빌드는 [Releases 페이지](https://github.com/blixvip/stick/releases)에 올라갑니다. **Watch → Custom → Releases**로 알림을 받으세요.
- **먼저 영상으로**: [2분 소개 영상](https://blixvip.github.io/stick/#tour).

## 자주 묻는 질문

<details>
<summary><b>Stick은 무료인가요?</b></summary>

네. GPL-3.0 라이선스의 무료 오픈소스입니다. 계정, 워터마크, 유료 버전이 없습니다.
</details>

<details>
<summary><b>Pivot Animator 대체 프로그램인가요?</b></summary>

네. Pivot Animator 프로젝트(<code>.piv</code>)와 피규어(<code>.stk</code>)를 열고 다시 내보낼 수 있으며, 레이어 타임라인, 트윈, 효과, 손그림, WebGPU 렌더링이 추가되어 있습니다.
</details>

<details>
<summary><b>PC에서 Stick Nodes 프로젝트를 열 수 있나요?</b></summary>

네. Stick Nodes 피규어, 무비클립, 프로젝트를 가져와 Windows나 Linux 컴퓨터에서 계속 작업할 수 있습니다.
</details>

<details>
<summary><b>졸라맨 애니메이션은 어떻게 만드나요?</b></summary>

관절을 끌어 포즈를 잡고 <b>프레임 추가</b>(<kbd>A</kbd>)를 누른 뒤 포즈를 바꾸고 <kbd>스페이스</kbd>로 재생하세요. 프레임 사이 동작은 Stick이 채웁니다. 마지막으로 <b>내보내기</b>에서 MP4, GIF, TikTok 같은 프리셋을 고르세요.
</details>

<details>
<summary><b>오프라인에서도 되나요? 작품이 업로드되나요?</b></summary>

완전히 오프라인으로 작동합니다. 프로젝트는 내 컴퓨터에만 저장되고 업로드되지 않습니다.
</details>

## 소스에서 빌드

필요 환경: Node.js 22 이상, Python 3.11 이상.

```sh
git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # 데스크톱 앱(Electron)
npm run serve        # 또는 브라우저에서 편집기 열기: http://127.0.0.1:47831
```
