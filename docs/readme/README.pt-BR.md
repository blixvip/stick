## O que é o Stick?

**Stick** é um app desktop e web para **animação de bonecos palito**. Você arrasta as articulações para posar o boneco, adiciona um quadro, muda a pose e o Stick preenche o movimento entre eles. Tem linha do tempo com camadas, papel cebola, movimentos de câmera, efeitos visuais, pincéis para desenho à mão e um editor de rigs para personagens próprios.

Ele abre projetos do **Pivot Animator** (`.piv`, `.stk`) e do **Stick Nodes**, então você pode continuar suas animações antigas. Tudo roda no seu computador: sem conta, sem marca d’água, sem upload.

## Baixe o Stick

- **Compile você mesmo** com poucos comandos; veja [Compilar a partir do código](#compilar-a-partir-do-código). Roda como app desktop ou no navegador.
- **Instaladores:** versões para Windows (instalador e portátil) e Linux (AppImage) são publicadas na [página de Releases](https://github.com/blixvip/stick/releases). Clique em **Watch → Custom → Releases** para ser avisado.
- **Assista antes:** o [vídeo de 2 minutos](https://blixvip.github.io/stick/#tour).

⭐ **Dê uma estrela neste repositório** para acompanhar as novidades e ajudar outros animadores a encontrar o Stick.

## Perguntas frequentes

<details>
<summary><b>O Stick é grátis?</b></summary>

Sim. O Stick é grátis e de código aberto sob a licença GPL-3.0. Sem conta, sem marca d’água e sem versão paga.
</details>

<details>
<summary><b>É uma alternativa ao Pivot Animator?</b></summary>

Sim. O Stick abre projetos (<code>.piv</code>) e bonecos (<code>.stk</code>) do Pivot Animator e consegue exportá-los de volta, com camadas, interpolação, efeitos, desenho e renderização WebGPU.
</details>

<details>
<summary><b>Posso abrir projetos do Stick Nodes no PC?</b></summary>

Sim. O Stick importa bonecos, movieclips e projetos do Stick Nodes para você continuar no Windows ou Linux.
</details>

<details>
<summary><b>Como faço uma animação de boneco palito?</b></summary>

Pose o boneco arrastando as articulações, aperte <b>Adicionar quadro</b> (<kbd>A</kbd>), mude a pose e aperte <kbd>Espaço</kbd> para reproduzir. O Stick interpola o movimento. Depois clique em <b>Exportar</b> e escolha MP4, GIF ou uma predefinição como TikTok.
</details>

<details>
<summary><b>Funciona offline? Ele envia minhas animações?</b></summary>

Funciona totalmente offline. Seus projetos ficam no seu computador; nada é enviado.
</details>

## Compilar a partir do código

Requisitos: Node.js 22+ e Python 3.11+.

```sh
git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # app desktop (Electron)
npm run serve        # ou o editor no navegador: http://127.0.0.1:47831
```
