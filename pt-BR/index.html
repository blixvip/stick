O que é o Stick?

Stick é um app desktop e web para animação de bonecos palito. Você arrasta as articulações para posar o boneco, adiciona um quadro, muda a pose e o Stick preenche o movimento entre eles. Tem linha do tempo com camadas, papel cebola, movimentos de câmera, efeitos visuais, pincéis para desenho à mão e um editor de rigs para personagens próprios.

Ele abre projetos do Pivot Animator (.piv, .stk) e do Stick Nodes, então você pode continuar suas animações antigas. Tudo roda no seu computador: sem conta, sem marca d’água, sem upload.

Recursos

Pose qualquer articulação

Arraste mãos e pés; a cinemática inversa (IK) dobra cotovelos e joelhos para você. Trava de ângulo, nós elásticos e partes 3D.

Keyframes e reprodução

Adicione um quadro, mude a pose e aperte play. Interpolação, curvas de suavização e reprodução WebGPU em tempo real.

Uma linha do tempo de verdade

Faixa de quadros simples ou linha do tempo avançada com camadas, pastas, chaves, suavização, intervalos, papel cebola e trilhas de áudio.

Efeitos integrados

Brilho, aura, sombra, desfoque, partículas, raios de energia, explosões, fumaça e power-ups, animáveis por quadro.

Desenhe em qualquer quadro

Tinta, pincel, lápis, caneta, marcador, carvão, aerógrafo, giz, óleo e mais. Misture desenho à mão com seus rigs.

Crie seus próprios rigs

Monte personagens com linhas, círculos, polígonos, texto e imagens. Comece por exemplos como engrenagens, leques, caixas e formas 3D.

Todos os comandos a uma busca

Aperte F1 ou Ctrl+P para achar qualquer comando. Todos os atalhos podem ser alterados.

Claro ou escuro, em 27 idiomas

Tema escuro por padrão, tema claro quando quiser, escala de interface ajustável e layout de toque para tablets.

Exporte para qualquer lugar

Predefinições de um clique para YouTube, YouTube Shorts, TikTok, Instagram Reels, X, GIFs para chat, PNGs transparentes e 4K. Exporte MP4, WebM (com transparência), GIF, APNG, sequências PNG / JPEG / SVG ou arquivos editáveis .piv e .stk.

Perguntas frequentes

O Stick é grátis?

Sim. O Stick é grátis e de código aberto sob a licença GPL-3.0. Sem conta, sem marca d’água e sem versão paga.

É uma alternativa ao Pivot Animator?

Sim. O Stick abre projetos (.piv) e bonecos (.stk) do Pivot Animator e consegue exportá-los de volta, com camadas, interpolação, efeitos, desenho e renderização WebGPU.

Posso abrir projetos do Stick Nodes no PC?

Sim. O Stick importa bonecos, movieclips e projetos do Stick Nodes para você continuar no Windows ou Linux.

Como faço uma animação de boneco palito?

Pose o boneco arrastando as articulações, aperte Adicionar quadro (A), mude a pose e aperte Espaço para reproduzir. O Stick interpola o movimento. Depois clique em Exportar e escolha MP4, GIF ou uma predefinição como TikTok.

Funciona offline? Ele envia minhas animações?

Funciona totalmente offline. Seus projetos ficam no seu computador; nada é enviado.

Compilar a partir do código

Requisitos: Node.js 22+ e Python 3.11+.

git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # app desktop (Electron)
npm run serve        # ou o editor no navegador: http://127.0.0.1:47831
