## What is Stick?

**Stick** is a desktop and web app for **stick figure animation**. You drag a figure's joints to pose it, add a frame, pose it again, and Stick fills the motion in between. It has a real timeline with layers, onion skin, camera moves, visual effects, brushes for hand-drawn frames, and a rig builder for custom characters.

It opens **Pivot Animator** (`.piv`, `.stk`) and **Stick Nodes** projects, so you can bring your old animations with you. Everything runs on your own computer: no account, no watermark, no uploads.

### Export anywhere

One-click presets for **YouTube**, **YouTube Shorts**, **TikTok**, **Instagram Reels**, **X**, chat **GIFs**, transparent PNG frames and 4K. Export **MP4**, **WebM** (with transparency), **GIF**, **APNG**, **PNG / JPEG / SVG** sequences, or editable `.piv` and `.stk` files.

### Everything else

- **Camera moves:** pan, zoom, shake and follow a figure, with presets and a motion graph.
- **Motion paths** you can drag, **inbetween** generation, mirror, join and duplicate tools.
- **Movieclips and a library** of reusable figures and animations.
- **Audio tracks** for lip sync and timing.
- **Recovery** saves your work in the background, and failed saves never overwrite your file.
- **Private by design:** decoding, editing, saving and rendering all happen on your device.

## FAQ

<details>
<summary><b>Is Stick free?</b></summary>

Yes. Stick is free and open source under the GPL-3.0 license. There is no account, no watermark and no paid tier.
</details>

<details>
<summary><b>Is Stick a Pivot Animator alternative?</b></summary>

Yes. Stick opens Pivot Animator projects (<code>.piv</code>) and figures (<code>.stk</code>), and can export them back. It adds a layered timeline, tweening, effects, drawing and a modern WebGPU renderer.
</details>

<details>
<summary><b>Can I open Stick Nodes projects on PC?</b></summary>

Yes. Stick imports Stick Nodes figures, movieclips and projects, so you can keep working on a Windows or Linux computer.
</details>

<details>
<summary><b>How do I make a stick figure animation?</b></summary>

Pose the figure by dragging its joints, press <b>Add frame</b> (<kbd>A</kbd>), change the pose, and press <kbd>Space</kbd> to play. Stick tweens the motion between frames. Then click <b>Export</b> and choose MP4, GIF or a preset like TikTok.
</details>

<details>
<summary><b>Can I export to MP4, GIF or transparent video?</b></summary>

Yes: MP4, WebM with transparency, GIF, APNG and PNG, JPEG or SVG frames, plus presets for YouTube, Shorts, TikTok, Instagram and X.
</details>

<details>
<summary><b>Does it work offline? Does it upload my animations?</b></summary>

It works fully offline. Your projects stay on your computer; nothing is uploaded.
</details>

<details>
<summary><b>Which platforms and languages are supported?</b></summary>

Windows and Linux desktop apps, plus a browser version (Chrome, Edge, Firefox and Safari 16.4+). macOS builds from source but is not tested yet. The interface is translated into 27 languages, including Chinese, Japanese, Korean, Spanish, Portuguese, French, German and Russian.
</details>

## Build from source

Requirements: Node.js 22+ and Python 3.11+.

```sh
git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # desktop app (Electron)
npm run serve        # or the editor in your browser at http://127.0.0.1:47831
```

Packaging, on the matching operating system:

```sh
python -m pip install -r scripts/requirements-build.txt
npm run build:sidecar
npm run pack && npm run verify:package
npm run dist:win     # or dist:linux, dist:mac
```

Browser build: `npm run web:build`, then `npm run web:preview`. More in [Web build](docs/WEB.md), [Linux](docs/LINUX.md) and [Touch interface](docs/TOUCH.md).

<details>
<summary><b>Tests and project layout</b></summary>

```sh
npm run check        # syntax, stylesheet lint
npm test             # unit tests
python -m unittest discover -s backend -p "test_*.py"
```

Browser tests (`tests/*.browser.mjs`) run against `npm run serve`, for example `node tests/timeline.browser.mjs`.

| Location | Responsibility |
| --- | --- |
| `src/editor*.mjs`, `src/pivot/` | Document model, commands, undo/redo, rigs |
| `src/renderer*.mjs` | WebGPU rendering and playback |
| `src/import-*.mjs`, `backend/`, `codecs/`, `native/` | Pivot and Stick Nodes import, codec service |
| `src/document-export*.mjs`, `src/video-export.mjs` | Saving, recovery, image and video export |
| `src/app.mjs`, `src/shell/`, `src/ui/`, `src/styles/` | Interface, workspaces, timelines and styles |
| `src/locales/` | Translations |
| `desktop/` | Electron app, file access, updates |
| `docs/` | Feature contracts and architecture; start with [ARCHITECTURE.md](docs/ARCHITECTURE.md) |

</details>
