Stick 是什麼？

Stick 是一款用來製作火柴人動畫的桌面與網頁應用程式。拖曳關節擺出姿勢，新增一個影格，再換個姿勢，Stick 就會自動補間中間的動作。它擁有含圖層的時間軸、洋蔥皮、鏡頭運動、視覺特效、手繪筆刷，以及自訂角色的骨架編輯器。

它可以開啟 Pivot Animator（.piv、.stk）與 Stick Nodes 專案，舊作品能直接繼續編輯。所有處理都在你的電腦上完成：不需帳號、沒有浮水印、不會上傳。

功能

隨心擺姿勢

拖曳手腳，反向運動學（IK）會自動彎曲手肘和膝蓋。支援角度鎖定、可伸縮節點和 3D 部件。

關鍵影格與播放

新增影格、改變姿勢、按下播放。補間、緩動曲線與即時 WebGPU 播放讓長動畫依然流暢。

專業時間軸

簡易影格條或進階時間軸：圖層、資料夾、關鍵影格、緩動、播放範圍、洋蔥皮與音軌。

內建特效

發光、光環、陰影、模糊、粒子、能量光束、爆炸、煙霧與能量提升，可逐格設定關鍵影格。

在任何影格上手繪

墨水、毛筆、鉛筆、代針筆、麥克筆、炭筆、噴槍、粉筆、油畫等筆刷，手繪與骨架動畫自由混合。

打造自己的角色

用線條、圓形、多邊形、文字和圖片製作角色，可從齒輪、摺扇、箱子與 3D 形狀等範例開始。

一鍵搜尋所有指令

按 F1 或 Ctrl+P 找到任何指令，所有快捷鍵都能自訂。

深色或淺色，27 種語言

預設深色主題，也可切換淺色；支援介面縮放與平板觸控版面。

隨處匯出

一鍵預設：YouTube、YouTube Shorts、TikTok、Instagram Reels、X、聊天用 GIF、透明 PNG 序列與 4K。可匯出 MP4、WebM（含透明）、GIF、APNG、PNG / JPEG / SVG 序列，以及可編輯的 .piv 與 .stk 檔案。

常見問題

Stick 免費嗎？

Stick 完全免費，採用 GPL-3.0 授權開源。不需帳號，沒有浮水印，也沒有付費版本。

Stick 可以取代 Pivot Animator 嗎？

可以。Stick 能開啟 Pivot Animator 的專案（.piv）與人物（.stk），也能匯出回去，並加入分層時間軸、補間、特效、手繪與現代 WebGPU 繪圖。

可以在電腦上開啟 Stick Nodes 專案嗎？

可以。Stick 能匯入 Stick Nodes 的人物、影片片段與專案，讓你在 Windows 或 Linux 電腦上繼續創作。

要怎麼製作火柴人動畫？

拖曳關節擺好姿勢，按 新增影格（A），改變姿勢，再按 空白鍵 播放。Stick 會補間影格之間的動作。最後按 匯出，選擇 MP4、GIF 或 TikTok 等預設。

可以離線使用嗎？會上傳我的作品嗎？

完全可以離線使用。你的專案只存在自己的電腦上，不會上傳。

從原始碼建置

需求：Node.js 22+ 與 Python 3.11+。

git clone https://github.com/blixvip/stick.git
cd stick
npm ci
python -m pip install -r backend/requirements-fast.txt
npm start            # 桌面應用程式（Electron）
npm run serve        # 或在瀏覽器中開啟編輯器: http://127.0.0.1:47831
